# FLT18355 Nekos

## How do I install these formulae?

`brew install flt18355/nekos/<formula>`

Or `brew tap flt18355/nekos` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "flt18355/nekos"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
